# 🔬 Лабораторная работа: Рефлексия в C# (Reflection API)

Этот проект представляет собой реализацию лабораторной работы по изучению механизма **рефлексии (System.Reflection)** и **позднего связывания (Late Binding)** в C#. 

Программа демонстрирует, как получать метаданные о типах во время выполнения, динамически создавать объекты, нарушать инкапсуляцию (читать и изменять приватные поля), а также реализовывать простейшую архитектуру плагинов.

---

## 🎯 Цели проекта
* Изучение работы с классом `System.Type`.
* Инспекция членов классов (поля, методы, свойства).
* Использование `Activator.CreateInstance` для динамического создания объектов.
* Работа с приватными членами класса (чтение/изменение приватных полей, вызов приватных методов).
* Реализация динамической загрузки плагинов (позднее связывание).

---

## 🗂 Структура проекта и реализованные задания

Проект разделен на логические блоки, каждый из которых соответствует заданиям из методических указаний:

### 🔹 Задания 1, 2, 3: Базовая рефлексия (`Tasks123.cs`)
* **Класс `UserProfile`**: Подопытный класс с инкапсулированной логикой и валидацией данных.
* **Инспекция методов**: С помощью `GetMethods` с флагами `BindingFlags` извлекаются все методы класса. Отфильтрованы служебные методы свойств (`get_` и `set_`).
* **Динамическое создание**: Использование `Activator.CreateInstance` для создания объектов `UserProfile` через конструктор по умолчанию и конструктор с параметрами, а также заполнение свойств через `PropertyInfo.SetValue`.

### 🔹 Задания 4, 5, 6: Работа с приватными членами (`Tasks456.cs`)
* **Класс `BlackBox`**: Класс-"чёрный ящик" с приватным полем `_secretData` и приватным методом `CalculateSecretFormula`.
* **Взлом инкапсуляции**: 
  * Получение доступа к приватному полю через `FieldInfo` и изменение его значения (взлом секретного кода).
  * Перехват исключения при попытке доступа к несуществующему полю.
* **Вызов приватных методов**: Вызов скрытого метода двумя способами:
  1. Через метод `MethodInfo.Invoke`.
  2. Через создание строго типизированного делегата `Delegate.CreateDelegate` (работает быстрее, чем `Invoke`).

### 🔹 Задание 7: Динамическая загрузка плагинов (`Task7.cs`)
* **Интерфейс `IPlugin`**: Базовый контракт для всех плагинов.
* **Плагины `CalculatorPlugin` и `LoggerPlugin`**: Реализации интерфейса.
* **Позднее связывание**: Программа сканирует текущую сборку (`Assembly.GetExecutingAssembly()`), находит все типы, реализующие `IPlugin`, динамически создает их экземпляры и вызывает метод `Execute`.

## 🚀 Как запустить проект

1. Убедитесь, что у вас установлен [.NET SDK](https://dotnet.microsoft.com/download).
2. Склонируйте репозиторий или скачайте исходный код.
3. Откройте терминал в папке с файлом проекта (`.csproj`) или исходниками.
4. Выполните команду запуска:
   ```bash
   dotnet run
   ```
   *Альтернативно: откройте проект в Visual Studio / Rider и нажмите `F5`.*

## 📚 Теоретическая справка

**Рефлексия** — это мощный инструмент, который позволяет программе изучать саму себя. Основные используемые классы из пространства имен `System.Reflection`:
* `Type` — содержит информацию о классе/интерфейсе.
* `MethodInfo` — информация о методах.
* `FieldInfo` / `PropertyInfo` — информация о полях и свойствах.
* `BindingFlags` — флаги поиска, позволяющие добраться до `Private` и `Static` членов.
* `Activator` — класс для инстанцирования объектов на лету.
